# 策略退役标准（预注册）
**预注册日**: 2026-09-18（模拟仓重置同日）｜**生效**: 即刻
**原则**: 退役条件在部署前写死，不在回撤时临时发明（预承诺防自欺）。

## 1. 验证期判定（20 个交易日 / ≥10 笔，从 2026-09-18 起算）
到期按以下**预注册标准**二选一，不允许事后调整：

**晋级（继续投入）**——全部满足：
- t20 扣成本（60.3bps/回合 + 卖侧摩擦）后净超额 > 0
- 期间最大回撤 < 15%（与熔断线一致）
- ≥10 笔样本（不足则顺延，每顺延 20 日重判）

**降级（周频观察）**——任一命中：
- 净超额 ≤ 0 但 > -5%
- t20 胜率 < 45%

**退役（停用短线档）**——任一命中：
- 净超额 ≤ -5%
- 最大回撤 ≥ 15%（熔断触发即视为预注册条件命中）
- 顺延两个周期仍 < 10 笔（样本积累能力失败）

## 2. 运行期 tripwire（验证期内持续监控）
- **滚动 20 日实时超额较回测同期（OOS +74.6%）衰减 > 50%** → 降频审查
- **t1 胜率连续 20 笔 < 50%**（基线 61.5%）→ 信号质量退化审查
- **15% 熔断**（trading_permission + risk_state，已有）→ 触发即暂停开仓，人工复盘后才可复位

## 3. 分档处置（tier 归因驱动）
- 激进档（t20 +7.22%）为当前最强信号源，验证期重点观察
- 稳健档/价值档（t20 为负且 n<8）：**无新数据前不得恢复推送**；验证期内持续为负 → 正式砍档

## 4. 不可豁免项
- 熔断（15%）无冷却豁免（risk-management skill 例外条款不适用于本验证期）
- 验证期内不改回测参数、不改门槛（发现 bug 修复除外，须记 CHANGE_LEDGER）
